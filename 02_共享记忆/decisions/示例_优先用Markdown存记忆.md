# 示例决策：优先用 Markdown 存记忆

> ⚠ 虚构决策，用于演示「decisions」写法。

## 决定
长期记忆以 Markdown 文件形式存在 Git 仓库中，而不是只存在某个聊天窗口里。

## 理由
1. 人类可在 Obsidian 直接编辑  
2. 多 Agent / 多设备可通过 Git 同步  
3. 便于审查与回滚  

## 后果
- 需要遵守一事一笔记与 frontmatter 约定  
- 密钥等敏感信息不得入库
