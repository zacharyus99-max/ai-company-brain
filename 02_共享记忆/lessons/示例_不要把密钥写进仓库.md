# 示例教训：不要把密钥写进仓库

> ⚠ 虚构教训，用于演示「lessons」写法。

## 现象
若有人把 API Key 写进笔记并 push，任何有仓库权限的人都能看到。

## 教训
- 凭证只放密码管理器 / 系统密钥环  
- 笔记里最多写「凭证别名」或「存放位置」  
- `.env`、`*.pem` 已由 `.gitignore` 忽略，仍不要故意添加  

## 以后怎么做
发现疑似密钥 → 立即轮换 → 从 Git 历史清理（需人类操作）→ 在日记记录。
