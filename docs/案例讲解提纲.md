# 案例讲解提纲 · AI 员工的共同大脑

> 供小红书 / 抖音 / 视频号口播或图文使用。全程用**通用概念**与虚构「项目A / 项目B」，不吹数据。

---

## 建议标题（择一）

1. 给 AI 员工装一个「共同大脑」：Obsidian + GitHub  
2. 多个 Agent 如何共享长期记忆？（模板开源思路）  
3. 不用再口头对线：我的 AI 团队读写同一份知识库  
4. 3 分钟搭好 AI 公司知识库（本地可看、云端可同步）  
5. 人类用 Obsidian 改，Agent 用 Git 写——同一份记忆

## 60 秒口播结构

| 秒 | 说什么 |
|---|---|
| 0–8 | 痛点：每个 AI 聊完就忘；换一个 Agent 又要从头讲项目A、项目B |
| 8–20 | 概念：做一份「公司大脑」——Markdown 知识库；Agent-1 研究、Agent-2 运营、Agent-3 客服都读写同一处 |
| 20–35 | 怎么看：用 Obsidian 打开，像文件夹一样浏览公司总览、花名册、共享记忆、项目、日志 |
| 35–50 | 怎么同步：GitHub 当云端；Obsidian Git 自动拉推，或一条 sync 脚本；本地改了云端有，Agent 推了你刷新就能见 |
| 50–60 | 行动：复制模板 → 改成你的公司名 → 把系统提示词片段贴进任意 Agent → 先让它读 INDEX |

---

## 5 个卖点（条目，勿编造数据）

1. **长期记忆在文件里，不在对话框里** — 关聊天也不丢  
2. **多 Agent 共用一份真相** — 研究员写的事实，客服也能引用  
3. **人类可读可改** — Obsidian 预览、双向链接、搜索  
4. **本地 ↔ GitHub 双向同步** — 插件或脚本，流程透明  
5. **规则写死在 AGENTS.md** — 一事一笔记、禁密钥、有模板，降低乱写概率
